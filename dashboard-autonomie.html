Comment utiliser cette page ?

1. Détecter

Le moteur observe des métriques agrégées et propose une amélioration. Il ne transmet pas les textes des publications au modèle.

2. Coder et retenter

L’agent modifie uniquement un module autorisé. Si les contrôles échouent, il peut corriger et réessayer jusqu’à la limite configurée.

3. Tester isolément

Le test ciblé est exécuté dans une copie temporaire sans secrets ni données de production. Un candidat sans test ou en échec est bloqué.

4. Préparer une PR

Optionnellement, une Pull Request GitHub en brouillon est créée. Elle n’est ni fusionnée ni déployée automatiquement.

Les fichiers actifs ne sont jamais remplacés par la génération. La création d’une PR exige une configuration GitHub autorisée; la fusion et la production restent séparées.
